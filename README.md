# Linux Automation Toolkit

A collection of powerful Linux automation scripts designed for system administrators, developers, and Linux enthusiasts.

## Features

- System monitoring
- Automatic backups
- Disk cleanup
- Security checks
- Process monitoring
- Log management

## Technologies

- Bash
- Python
- Linux Shell

## Scripts Included

### 1. System Monitor
Monitor CPU, RAM, disk usage, and uptime.

### 2. Backup Script
Automatically backup important files and directories.

### 3. Cleanup Tool
Remove temporary files and clean package cache.

### 4. Security Scanner
Basic Linux security checks and suspicious process detection.

## Usage

```bash
chmod +x script.sh
./script.sh
```
